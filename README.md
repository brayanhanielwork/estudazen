# EstudaZen — versão para GitHub Pages

Site estático de estudos de Fundamentos de Administração.

## Publicação pelo navegador

1. Crie um repositório no GitHub.
2. Extraia o ZIP **EstudaZen-GitHub-Leve.zip** no seu computador.
3. No repositório, escolha **Add file → Upload files**.
4. Envie **os cinco arquivos contidos na pasta `EstudaZen-GitHub`**, não o ZIP e nem a pasta contendo os arquivos; `index.html` precisa ficar na raiz.
5. Em **Settings → Pages → Build and deployment**, selecione **Deploy from a branch**, `main`, `/(root)`.
6. Aguarde a publicação e acesse `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Arquivos necessários

- `index.html`: página inicial
- `styles.css`: apresentação e responsividade
- `content.js`: aulas e questões
- `app.js`: interações, animações e armazenamento local
- `README.md`: estas instruções

Os PDFs originais e imagens conceituais fornecidos como referências **não são necessários para executar o site** e por isso foram retirados desta versão de publicação.

O ranking atual é local ao navegador, não compartilhado entre diferentes dispositivos. Correção da discursiva via IA exige integração externa.
